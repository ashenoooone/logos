# Бизнес-правила Logos

Краткая карта инвариантов для разработки и ревью, не замена критериям приёмки. Источник каждого правила — соответствующая неизменённая story. Неподтверждённые трактовки вынесены в [открытые вопросы](../open-questions.md).

## Учётные записи и доступ

| Область | Подтверждённое правило | Источник |
|---|---|---|
| Регистрация | Менеджера приглашает администратор. Некорректный или уже занятый email не создаёт аккаунт; один email — один аккаунт. | [#1](../stories/01-manager-registration.md) |
| Повторное приглашение | После исправления email новое приглашение приходит на новый адрес, старая ссылка недействительна. | [#1](../stories/01-manager-registration.md) |
| Установка пароля | Ссылка одноразовая, действует 72 часа; использованная или просроченная даёт «Ссылка устарела». После задания пароля менеджер сразу авторизован. | [#2](../stories/02-password-setup.md) |
| Политика пароля | При установке и смене: минимум 8 символов, буква любого алфавита и десятичная цифра; пароль не обрезается и не нормализуется, повтор совпадает точно. | [#2](../stories/02-password-setup.md), [#4](../stories/04-account-settings.md), [ADR-0008](../adr/0008-demo-feedback-and-manager-otp.md) |
| Вход менеджера | Email и одноразовый код; только после принятия приглашения. Нейтральный запрос для любого корректного email; 6 цифр, 10 минут, 5 попыток, повтор через 60 секунд отзывает старый код. | [#10](https://github.com/ashenoooone/logos/issues/10), [ADR-0008](../adr/0008-demo-feedback-and-manager-otp.md) |
| Вход администратора | Прежние CLI login и пароль; после 5 неверных попыток блокировка на 15 минут. OTP для администратора нет. | [ADR-0006](../adr/0006-first-authentication-scenario.md), [ADR-0008](../adr/0008-demo-feedback-and-manager-otp.md) |
| Запоминание входа | «Запомнить меня» выключено по умолчанию. С ним сессия до 30 дней, без него — до закрытия браузера. | [#3](../stories/03-login.md) |
| Смена email | Новый адрес становится рабочим только после подтверждения по ссылке; до подтверждения действует старый. | [#4](../stories/04-account-settings.md) |
| Смена пароля | Нужен верный текущий пароль и совпадающий повтор нового. «Выйти на других устройствах» включено по умолчанию; при этом текущая сессия сохраняется. | [#4](../stories/04-account-settings.md) |
| Восстановление | Отдельное восстановление пароля менеджера удалено; для входа используется email-код. Установка пароля по приглашению и смена в профиле сохраняются. | [#10](https://github.com/ashenoooone/logos/issues/10), [ADR-0008](../adr/0008-demo-feedback-and-manager-otp.md) |

## Каналы и переписка

| Область | Подтверждённое правило | Источник |
|---|---|---|
| Подключение | Администратор подключает мессенджер по токену. Неверный токен не подключает канал, ошибка видна администратору. | [#5](../stories/05-channels.md) |
| Сбой канала | У неработающего канала виден статус «ошибка», доступно переподключение. | [#5](../stories/05-channels.md) |
| Отключение | Новые сообщения из канала не приходят, старая переписка остаётся доступной. | [#5](../stories/05-channels.md) |
| Входящие | Единый список диалогов подключённых мессенджеров; доступны переписка, вложения и ответ, в том числе с файлом. | [#6](../stories/06-inbox.md) |
| Ошибка отправки | Статус «Не доставлено», повторная отправка, текст не теряется. «Доставлено» — успешный ответ Bot API (ADR-0007). | [#6](../stories/06-inbox.md) |
| Непрочитанные | Счётчик у диалога и общий над списком; открытие диалога помечает сообщения прочитанными. Новое сообщение даёт звук и счётчик вкладки браузера. | [#6](../stories/06-inbox.md) |
| Служебная команда | `/start` и `/start@bot` создают/обновляют карточку клиента, но не сообщение, непрочитанность или превью. Старая история очищается миграцией без потери остальной переписки. | [#10](https://github.com/ashenoooone/logos/issues/10) |
| Автор ответа | Сохраняется менеджер, отправивший ответ; повтор не меняет автора. Старые ответы без автора показываются нейтрально. Входящие подписаны именем клиента. | [#10](https://github.com/ashenoooone/logos/issues/10) |
| Поиск | По тексту всей переписки без учёта регистра, включая кириллицу; фильтры и сортировка продолжают применяться. | [#10](https://github.com/ashenoooone/logos/issues/10) |

## Сортировка, фильтры и теги

| Область | Подтверждённое правило | Источник |
|---|---|---|
| Порядок списка | По умолчанию последнее сообщение, новые сверху. Менеджер меняет сортировку, выбор сохраняется при следующем открытии. | [#7](../stories/07-sorting-and-filters.md) |
| Новые сообщения в списке | Не переставляют диалоги во время просмотра; уведомление «N новых сообщений» и «Показать» применяет обновление по выбранной сортировке. | [#7](../stories/07-sorting-and-filters.md) |
| Фильтры | Несколько фильтров и несколько значений одного фильтра; число найденных диалогов, отдельный сброс, пустое состояние со сбросом всех фильтров, сохранение набора под названием. Фильтры: канал, тег, статус непрочитанности; внутри фильтра ИЛИ, между фильтрами И (ADR-0007). | [#7](../stories/07-sorting-and-filters.md) |
| Назначение тега | Существующий или новый тег виден в диалоге и строке списка; созданный доступен создавшему менеджеру. | [#8](../stories/08-tags.md) |
| Регистр тегов | «Возврат» и «возврат» не создают два одинаковых тега; поиск без учёта регистра. Уникальность в рамках компании (ADR-0007). | [#8](../stories/08-tags.md) |
| Права на теги | Стандартные теги меняет и удаляет только администратор; менеджер может удалять только созданные им теги. | [#8](../stories/08-tags.md) |
| Удаление тега | Удалённый тег снимается с диалогов. Фильтрация по тегу относится к #7, не к #8. | [#8](../stories/08-tags.md) |

## Принятые границы проекта

Пользовательские решения, которых нет в исходных stories, записаны отдельно в [ADR-0001](../adr/0001-project-baseline.md) и [ADR-0006](../adr/0006-first-authentication-scenario.md). ADR-0006 явно разрешает конфликт выбора роли в #1 с поздним макетом, задаёт правила первого сценария и заменяет внешнюю доставку локальным Mailpit только для согласованного инкремента. Не подменять этим исходные stories и не считать внешнюю доставку выполненной.
