## User story

Как **менеджер**, я хочу добавлять теги к диалогам клиентов, чтобы разделять их по тематикам.

## Что нужно сделать

- Добавить возможность ставить тег на диалог: выбирать существующий или создавать новый.
- Показывать тег в диалоге и в строке списка; созданный тег должен быть доступен создавшему менеджеру.
- Искать теги без учёта регистра: вместо «возврат» предлагать существующий «Возврат» и не создавать второй такой же тег.
- Разрешить менять и удалять стандартные теги только администратору; при удалении тега снимать его с диалогов.
- Разрешить менеджеру удалять только созданные им теги.
- Отображение тегов в диалоге и в списке — по макету `LOG-32.png`. Фильтрация по тегу реализуется в 4.1.

## Критерии приёмки

- [ ] **Успешный сценарий.** Менеджер добавляет тег к диалогу, выбирает нужный или создаёт новый — тег появляется в диалоге и в строке списка, созданный тег доступен создавшему менеджеру.
- [ ] **Поиск тегов не зависит от регистра.** Вместо «возврат» предлагается существующий «Возврат», второй такой же тег не создаётся.
- [ ] **Стандартные теги** может менять и удалять только администратор; при удалении тег снимается.
- [ ] **Менеджер может удалять только созданные им теги.**
