## User story

Как **менеджер**, я хочу сортировать сообщения клиентов, чтобы быстро находить нужные.

## Что нужно сделать

- Сортировать диалоги по последнему сообщению (новые сверху) по умолчанию.
- Дать менеджеру менять сортировку на любую доступную и сохранять выбор при следующем открытии.
- Реализовать фильтры: несколько фильтров одновременно и несколько значений в одном фильтре; показывать количество найденных диалогов; давать сбросить каждый фильтр отдельно.
- Сделать пустое состояние, если по фильтрам ничего не найдено, со сбросом отдельных фильтров и кнопкой «Сбросить все фильтры».
- Дать сохранять текущий набор фильтров под своим названием и применять его одним нажатием.
- Не менять порядок диалогов, пока менеджер просматривает список: показывать сверху уведомление «N новых сообщений» с кнопкой «Показать»; после нажатия обновлять список по выбранной сортировке.

## Критерии приёмки

- [ ] При открытии списка диалоги по умолчанию отсортированы по последнему сообщению — новые сверху. Менеджер может изменить сортировку на любую доступную. Выбранная сортировка сохраняется при следующем открытии.
- [ ] Менеджер может применять несколько фильтров одновременно и выбирать несколько значений в одном фильтре. На экране видно количество найденных диалогов. Каждый фильтр можно сбросить отдельно.
- [ ] Если по выбранным фильтрам ничего не найдено, отображается пустое состояние с возможностью сбросить отдельные фильтры или нажать кнопку «Сбросить все фильтры».
- [ ] Менеджер может сохранить текущие фильтры под своим названием и позже применить их одним нажатием.
- [ ] Новые сообщения не меняют порядок диалогов, пока менеджер просматривает список. Сверху появляется уведомление «N новых сообщений» с кнопкой «Показать». После нажатия список обновляется, а новые диалоги добавляются в соответствии с выбранной сортировкой.
