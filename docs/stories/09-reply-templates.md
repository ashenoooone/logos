# 1.1 Шаблоны ответов

GitHub: [#11](https://github.com/ashenoooone/logos/issues/11), snapshot 2026-11-19, `updatedAt=2026-11-18T21:09:50Z`, без комментариев.

## История

Как **менеджер**, я хочу использовать шаблоны ответов, чтобы отправлять клиентам заранее подготовленные сообщения.

## Критерии приёмки

- [ ] Успешный сценарий: менеджер в диалоге нажимает «Шаблоны», выбирает нужный шаблон — текст подставляется в поле ввода, менеджер может его дописать и отправляет клиенту обычным способом. Шаблон сам по себе не отправляется.
- [ ] Если в шаблоне есть переменные, то перед вставкой менеджер видит их в предпросмотре; незаполненные переменные подсвечиваются, пока менеджер их не заполнит.
- [ ] Если шаблонов много, то менеджер находит нужный поиском по названию и тексту; пустой результат поиска показывает подсказку и кнопку «Создать шаблон».
- [ ] Крайний случай: менеджер без прав на редактирование видит шаблоны, но кнопки редактирования и удаления у него нет; удаление используемого шаблона не ломает уже отправленные сообщения.
