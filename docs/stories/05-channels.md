## User story

Как **администратор**, я хочу управлять мессенджерами, чтобы менеджеры получали сообщения от клиентов.

## Что нужно сделать

- Реализовать раздел «Каналы» и форму подключения по макету `LOG-29.png`.
- Подключать мессенджер по токену: при успехе канал получает статус «подключён», после чего сообщения клиентов из него получают менеджеры (3.2).
- При неверном токене не подключать канал и показывать администратору ошибку.
- Отслеживать состояние канала: при сбое показывать на карточке статус «ошибка» и давать возможность переподключить канал.
- Реализовать отключение канала: новые сообщения из него не приходят, старая переписка остаётся доступной.

## Критерии приёмки

- [ ] **Успешный сценарий.** Администратор в разделе «Каналы» подключает мессенджер, указав токен: канал получает статус «подключён», после чего сообщения клиентов из этого мессенджера получают менеджеры (3.2).
- [ ] **Неверный токен.** Канал не подключается, администратор видит ошибку.
- [ ] **Канал перестал работать.** На карточке статус «ошибка», канал можно переподключить.
- [ ] **Отключение канала.** Новые сообщения из него не приходят, старая переписка остаётся доступной.
