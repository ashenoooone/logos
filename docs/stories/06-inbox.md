## User story

Как **менеджер**, я хочу принимать сообщения клиентов, чтобы агрегировать сообщения из разных мессенджеров.

## Что нужно сделать

- Реализовать экран «Входящие» и диалог по макету `LOG-30.png`.
- Показывать диалоги из всех подключённых мессенджеров единым списком.
- Дать возможность открыть диалог, прочитать переписку и вложения.
- Реализовать ответ клиенту, при необходимости — с файлом; показывать у ответа статус «доставлено».
- Добавить уведомления о новом сообщении: звук и счётчик на вкладке браузера.
- Показывать число непрочитанных у диалога и общее число над списком; открытие диалога помечает сообщения прочитанными.
- Обработать ошибку отправки: показывать «Не доставлено», давать отправить повторно и не терять текст ответа.

## Описание

Как **менеджер**, я хочу принимать сообщения клиентов, чтобы агрегировать сообщения из разных мессенджеров.

Экран «Входящие» и диалог — по макету (файл `LOG-30.png` в чате задачи).

## Критерии приёмки

- [ ] **Успешный сценарий.** Менеджер во «Входящих» видит диалоги из всех подключённых мессенджеров одним списком, открывает диалог, читает переписку и вложения, отвечает (при необходимости — с файлом): ответ уходит клиенту, у ответа видно «доставлено».
- [ ] **Новое сообщение.** Менеджер узнаёт о нём по звуку и по счётчику на вкладке браузера; у диалога видно число непрочитанных, общее число — над списком; открытие диалога помечает сообщения прочитанными.
- [ ] **Ответ не ушёл.** У ответа «Не доставлено», его можно отправить повторно, текст ответа не теряется.
