# ADR-0003: менеджер пакетов и маршрутизация фронтенда

- Дата: 2026-11-04.
- Статус: **принято пользователем** при подготовке передачи фронтенд-этапу.

## Context

Бэкенд технически инициализирован; фронтенд ещё не создан. React и Mantine UI уже выбраны в [ADR-0001](0001-project-baseline.md). Нужны решения о менеджере пакетов и клиентской маршрутизации до начала отдельной фронтенд-сессии.

## Decision

- **Решили:** использовать **pnpm** как менеджер пакетов фронтенда и **TanStack Router** для маршрутизации React-приложения.
- **Почему:** пользователь явно выбрал оба инструмента.
- **Отвергли:** npm/Yarn как менеджеры пакетов проекта и другой клиентский роутер вместо TanStack Router в текущем фронтенд-этапе.

## Consequences

- Фронтенд-этап должен зафиксировать совместимые версии инструментов и создать `pnpm-lock.yaml`; не смешивать lock-файлы разных JavaScript-менеджеров пакетов.
- Версии Node.js, pnpm, React, Mantine и TanStack Router, сборка, язык приложения, форма объявления маршрутов и инструменты проверок ещё не выбраны.
- Выбор TanStack Router не означает выбора TanStack Start, TanStack Query, SSR или изменения HTTP-контракта бэкенда.
- Фронтенд создаётся отдельной задачей. Эта запись не означает реализации экранов, маршрутов или stories #1–#8.
