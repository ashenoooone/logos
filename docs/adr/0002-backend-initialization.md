# ADR-0002: инструменты и техническая инициализация бэкенда

- Дата: 2026-11-04.
- Статус: **принято пользователем** в задаче технической инициализации.

## Context

Нужны запускаемый FastAPI-сервис, постоянная SQLite, миграции и закрытое создание первого администратора. Stories #1–#8, поля регистрации менеджеров и продуктовая политика пароля в задачу не входят. Исходные границы — [ADR-0001](0001-project-baseline.md).

## Decision

### Инструменты

- **Решили:** uv, Python 3.13; FastAPI и Uvicorn; синхронный SQLAlchemy 2 и Alembic; argon2-cffi для Argon2id; pytest, Ruff и mypy для проверок. Точные совместимые версии зависимостей фиксируются в `uv.lock`.
- **Почему:** воспроизводимое окружение, стандартные миграции и небольшой синхронный стек для SQLite без отдельного async-драйвера.
- **Отвергли:** Python 3.11 как базовую версию новой разработки; pip/venv с отдельным механизмом фиксации вместо uv. Другую СУБД не рассматриваем.

### Идентификатор первого администратора

- **Решили:** обязательный непустой технический `login`, точное сравнение без нормализации. Пароль вводится скрыто дважды, не передаётся аргументом командной строки и не имеет значения по умолчанию. Сохраняется только Argon2id-хеш.
- **Почему:** позволяет развернуть систему, не выдумывая поля регистрации, правила email и сложность пароля до просмотра макетов.
- **Отвергли:** email как обязательный идентификатор на этом этапе.
- Отказ от пустого секрета — техническая защита команды, а не продуктовая политика сложности паролей.

### Повтор создания

- **Решили:** при существующем первом администраторе команда завершается с ненулевым кодом без изменения login и хеша. Ограничение единственного первого администратора обеспечивается также в БД, включая конкурирующие запуски.
- **Почему:** повторное развёртывание не должно молча менять пароль или выдавать пропуск за создание.
- **Отвергли:** успешный пропуск для того же login; неявный сброс пароля; создание второго администратора этой командой.

## Consequences

- Миграции выполняются явно перед запуском; HTTP не создаёт администратора и не применяет миграции автоматически.
- Путь к файлу SQLite настраивается окружением. Данные и резервные копии остаются ответственностью владельца установки; production-среда и схема резервного копирования пока не выбраны.
- Начальный запуск — один процесс Uvicorn; конкурентную продуктовую обработку сообщений этим решением не проектируем.
- Техническая учётная запись не означает реализации входа, сессий, регистрации, приглашений или восстановления пароля.
- Фактические команды и реализованный HTTP-контракт документируются после проверки приложения.
