# Logos

Единое рабочее место менеджера для переписки с клиентами через подключённые мессенджеры.

## Состояние проекта

Сейчас в репозитории **только документация**. Приложение, зависимости, схема БД, миграции, команды запуска и автоматические проверки ещё не созданы. Ни одна пользовательская история не реализована.

Проверены все 8 открытых [GitHub issues](https://github.com/ashenoooone/logos/issues) и подготовлены их локальные копии. Дата снимка и соответствие файлов — в [индексе историй](docs/stories/README.md).

## Принятые решения

- **Сервер:** Python + FastAPI.
- **Клиент:** React + Mantine UI.
- **База данных:** SQLite.
- **Границы:** одна установка для одной компании.
- **Первая интеграция:** Telegram Bot API, бот по токену.
- **Первый администратор:** закрытая команда развёртывания, без публичной регистрации.

Источник и последствия решений: [ADR-0001](docs/adr/0001-project-baseline.md). Дополнительные библиотеки, версии и инструменты пока не выбраны.

## Как начинать задачу

1. Найти историю в индексе, прочитать её критерии и зависимости.
2. Сверить её с актуальным issue и комментариями в GitHub. Локальная копия — снимок, а не гарантия актуальности.
3. Прочитать относящиеся к задаче правила, ADR и открытые вопросы. Остальную базу знаний не загружать.
4. Если задача зависит от макета — открыть вложения истории и выяснить актуальную версию до реализации.
5. Реализовать полный сценарий и проверить его критерии. Исходные stories не переписывать ради плана или отчёта.

## Следующий этап

Техническая инициализация выбранного стека: выбрать минимальные инструменты, создать приложение и конфигурацию SQLite, миграции, проверки и закрытую команду создания администратора. Реальные команды запуска добавить сюда после появления конфигурации.

Первый продуктовый сценарий — связка приглашения менеджера, задания пароля и входа (#1–#3). Предлагаемый порядок остальных историй и взаимные зависимости описаны в индексе; это не утверждённый спринт.

До реализации регистрации нужно извлечь из макетов поля и точную политику пароля. До приёмки Telegram — согласовать значение статуса «доставлено» с реальными возможностями Bot API.
