# Password

Пароль менеджера по одноразовому приглашению.

## Публичный API

- `PasswordSetupFlow` — экран `/invitation`: токен из `#token=…` (фрагмент сразу убирается из адреса), `preview`, форма с подсказками политики, `410` — «Ссылка устарела», успех — новая сессия и переход на главную.

Токен уходит только в JSON-теле POST; в URL, query и логах его нет.
