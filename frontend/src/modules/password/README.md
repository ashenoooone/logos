# Password

Пароль менеджера по одноразовой ссылке и запрос восстановления.

## Публичный API

- `PasswordSetupFlow flow="invitation" | "reset"` — экран `/invitation` или `/password-reset`: токен из `#token=…` (фрагмент сразу убирается из адреса), `preview`, форма с подсказками политики, `410` — «Ссылка устарела», успех — новая сессия и переход на главную.
- `ForgotPasswordForm` — `POST /password-reset/request`: одинаковый ответ для любого email, подсказка про «Спам», повтор не чаще раза в 60 с (`429` задаёт оставшееся время).

Токен уходит только в JSON-теле POST; в URL, query и логах его нет.
