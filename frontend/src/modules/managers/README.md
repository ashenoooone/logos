# Managers

Раздел администратора «Сотрудники»: `GET /admin/managers`, `POST /admin/managers`, `POST /admin/managers/{id}/invitation`.

## Публичный API

- `ManagersPanel` — список, форма «Новый менеджер» (имя и email; роль фиксирована), повтор приглашения ожидающему менеджеру с исправлением email. Ошибка SMTP (`502`) показывается как сохранённый, но не приглашённый менеджер.

Доступ проверяет guard маршрута; `401` от API сбрасывает сессию.
