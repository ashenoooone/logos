# Templates

Шаблоны ответов (#11): `GET|POST /templates`, `PATCH|DELETE /templates/{id}`. Только менеджер; шаблоны общие на компанию.

## Публичный API

- `ReplyTemplates` — кнопка «Шаблоны» и диалог: поиск по названию и тексту, предпросмотр с переменными `{клиент}`, `{номер}`, `{дата}` (незаполненные подсвечены, кнопка «Вставить в ответ» заблокирована), создание, изменение и удаление **своих** шаблонов. Чужие шаблоны видны только для вставки.
- `templatesQueryOptions` — список шаблонов.

`401` сбрасывает сессию. Шаблон не отправляется сам: он подставляет текст в поле ввода через `onInsert`.
