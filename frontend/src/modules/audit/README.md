# Audit log

Журнал действий (#18): `GET /admin/audit-log` с фильтрами `actor`, `action`, `from`, `to` и `POST /admin/audit-log/export` (CSV, до 100 000 строк). Только администратор.

## Публичный API

- `AuditLogPanel` — раздел «Журнал действий»: фильтры по сотруднику, типу и датам, таблица только для чтения, выгрузка CSV.
- `AuditEvent`, `AuditActor`, `AuditFilters`, `AuditAction` — типы для страницы и фильтров.

`401` сбрасывает сессию. Без выбранных фильтров сервер отдаёт последние 7 дней; записи неизменяемы, срок хранения — 12 месяцев.
