# Tags

Теги диалогов (#8): `GET /tags`, `DELETE /tags/{id}`, `POST /conversations/{id}/tags`, `DELETE /conversations/{id}/tags/{tag_id}`; администратор — `GET|POST /admin/tags`, `PATCH|DELETE /admin/tags/{id}`.

## Публичный API

- `ConversationTags` — строка «Теги:» в диалоге: снять тег, поставить существующий по стабильному ID или явно создать новый по имени; удалить свой тег.
- `TagBadge` — цветной бейдж тега (строка списка, фильтры).
- `TagsAdminPanel` — раздел администратора «Теги»: создать стандартный, переименовать и удалить любой тег (с подтверждением, сколько диалогов затронет).
- `tagsQueryOptions` — все теги для фильтра «Тег» во «Входящих».

`401` сбрасывает сессию.
